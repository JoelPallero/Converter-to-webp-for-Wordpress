Convierte automáticamente todas las imágenes subidas a formato WebP con 100% de calidad. Incluye opción para convertir imágenes existentes por lotes o selección individual.

== Description ==

Nabi WebP Converter es una solución integral para optimizar el rendimiento de tu sitio WordPress mediante el uso del formato de imagen WebP. A diferencia de otros plugins, este se enfoca en la máxima calidad (100%) manteniendo el peso del archivo reducido.

**Características principales:**
* Conversión automática al subir nuevas imágenes.
* Conversión manual de imágenes existentes en la biblioteca de medios.
* Selección de imágenes individuales o por lotes para conversión.
* Soporte para múltiples tamaños de imagen de WordPress.
* Interfaz administrativa moderna y fluida.

== Installation ==

1. Sube la carpeta del plugin al directorio `/wp-content/plugins/`.
2. Activa el plugin a través del menú 'Plugins' en WordPress.
3. Ve a 'WebP Converter' en el menú de administración para comenzar la conversión.

== FAQ ==

= ¿Se borran las imágenes originales? =
No, el plugin crea una versión WebP pero mantiene el archivo original por compatibilidad.

= ¿Funciona con todos los navegadores? =
WebP es soportado por la gran mayoría de navegadores modernos (Chrome, Firefox, Edge, Safari).
